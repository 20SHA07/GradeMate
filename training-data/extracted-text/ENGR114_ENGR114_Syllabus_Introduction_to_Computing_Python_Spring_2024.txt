ENGR 114 Introduction to Computing - Python
(3 Lectures, 1 Tutorial, 2 Laboratories – 4 Credits)
Prerequisite: None
Course Catalog Description:
Introduction to computer systems: computer hardware components, operating system, compiling,
debugging, libraries, linking. Programming based problem solving that includes program development
lifecycle. Imperative programming: data types, conditional expressions and statements, repetitive
structures, arithmetic and logic operators, functions, arrays, strings, data structures (database, tuple),
file I/O.
Textbook:
Python Programming: Using Problem Solving approach by R. Thareja, Publisher: Oxford University
Press, 2017, ISBN: 978-0-19-948017-3
Reference Materials:
How to Think Like a Computer Scientist: Learning with Python 3 Documentation Release 3rd Edition,
Peter Wentworth, Jeffrey Elkner, Allen B. Downey and Chris Meyers, April 2018 (available online:
https://media.readthedocs.org/pdf/howtothink/latest/howtothink.pdf)
Course Topics:
1. Introduction to computer units and computer language: Machine language, Assembly Language
and High level language. (3 lectures)
2. Introduction to Python programming environment (IDLE, Wing IDE 101). (1 lecture + 1 lab)
3. Syntax and semantics concepts, memory concepts, basic data type declarations and their ranges,
output formatting for data types, assignments, arithmetic and logic operators, operators’
precedence, associativity. (3 lectures + 1 Lab)
4. Problem solving approaches, algorithms using pseudocode and flowchart. (3 lectures + 1 Lab)
5. Control structures I (selections): if, else, elif, selection structures. (3 lectures + 1.5 Labs)
6. Control structures II (repetitions): for, and while loop repetition structures, counter controlled vs.
sentinel controlled loop structures, nested loops, break and continue program control statements.
(4 lectures + 1.5 Labs)
7. Functions: passing information to and from functions, scope and visibility of identifiers, iterative
vs. recursive functions. Built in functions and user defined functions. (5 lectures + 2 Labs)
8. Lists: declaring, passing to functions, linear search, multi-dimensional, sorting. Manipulating of
Lists 1D and 2D. (4 lectures + 1 Lab).
9. Strings: Fundamentals of characters and strings, string manipulation functions in Python (ex: find,
len, etc.), string user defined functions (ex: upper, count, etc.). (4 lectures + 1 Lab)
10. Data Structures: dictionary, tuple, passing and returning to/from function. (4 lectures + 1 Lab)
11. File I/O: streams insertion and extraction, stream manipulators, open, read, write and update. (3
lectures + 1 Labs)
12. Scientific computing using NumPy arrays, Pandas DataFrames and Python plotting (matplotlib,
seaborn) (3 lectures + 2 labs)
13. Basic introduction to Artificial Intelligence (2 lectures + 1 lab)
Course Structure:
Lectures will be 3 x 50-minutes per week; Laboratory sessions will be 1 x 100 min per week; Tutorial
sessions will be 1 x 50 min per week.
