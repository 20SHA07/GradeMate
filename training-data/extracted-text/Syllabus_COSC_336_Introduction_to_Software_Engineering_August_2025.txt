COSC 336 Introduction to Software Engineering
(2 Lecture, 3 Laboratory – 3 Credits)
Prerequisite: COSC 230
Course Catalog Description:
The course introduces software engineering concepts and best practices. It discusses software
processes and project management concepts. The course elaborates on software requirements,
modeling, design, testing, and maintenance. It gives examples of unified modeling language diagrams
and emerging software development methods.

Course Topics:
1. Introduction to Software engineering, historical background. Definition of SE. SE Process. SE
Process Model. Key Challenges facing SE. (2 lectures)
2. The Software Process, Process Iteration: incremental and spiral development, Aspect- oriented
Software Development, Agile Development, Component-based development, process activities,
automated process support (CASE tools). (4 lectures)
3. Project Management Concepts: S/W management activities, S/W management structure, personnel
issues, planning & scheduling, Risk management. (2 lecture)
4. Software Requirements Engineering Using Unified Modeling Language (UML) Use-Cases:
Requirement engineering definition, requirements elicitation, and requirements specification.
Functional, non-functional & domain requirements. System and software requirements. UML use-
cases, use-case diagrams. (5 lectures)
5. System Models: Context models, behavioral models: data models, object models (4 lectures)
6. Architectural Design – The design process. Architectural design: Repository model, Client-server
architecture & Abstract Machine model. Control Modeling; Modular decomposition. Distributed
Systems Architectures. (5 lectures)
7. Object Oriented Software Design – Objects and Object Classes; Object Oriented Design Process;
Design Evolution. (4 lectures)
8. Testing & Maintenance – Language choice; coding practice, verification and validation, testing
strategies; Types of maintenance, system documentation, program evolution dynamics, maintenance
costs (2 lectures)
Course Structure and Learning Methodologies:
Lectures are 2 x 50 minutes. Laboratory sessions are 150 minutes per week in the laboratory.
The course material is presented using PowerPoint slides and lecture notes, available to the students
through Blackboard. The course involves group homework/assignments and projects that involve
students in a self-learning environment.
