COSC 495 Introduction to Game Development and XR
(3 Lecture – 3 Credit s)
Prerequisite: COSC 230
Course Catalog Description:
This course provides students with the fundamentals of video game development and extended reality
(XR) technologies, focusing on building interactive 2D and 3D games and XR applications. The
course covers the game development process from concept to prototype.
Textbook:
Introduction to Game Design, Prototyping, and Development: From Concept to Playable Game with
Unity and C#, by Jeremy Gibson Bond, Third Edition, Addison-Wesley Professional, 2022
ISBN-13: 978-0321933164
https://www.amazon.com/Introduction-Game-Design-Prototyping-Development-dp-
0136619940/dp/0136619940/ref=dp_ob_image_bk
Reference Materials:
Unity Official Documentation and Tutorials: https://learn.unity.com/
Course Topics:
1. Introduction to Game Development
a. Game design principles, genres, and development pipelines, History of video games
and the evolution of game development, Introduction to game theory and its application
in game design (1 lecture)
2. Unity Basics and Scripting
a. Unity interface, tools, and basic C# scripting (2 lectures)
b. Game asset creation and management (2 lectures)
c. Lighting and shading, and audio design and implementation (2 lectures)
d. Advanced Scripting, code optimization, and version control (2 lectures)
e. 2D and 3D game development (2 lectures)
3. Extended Reality (XR) Technologies
a. XR concepts, technologies, and hardware (1 lecture)
b. XR design principles: immersion, presence, and interaction paradigms. (1 lecture)
c. Design and prototyping intuitive and immersive XR applications (1 lecture)
d. Unity XR toolkit and SDKs (AR Foundation, VR frameworks (Halolen)) (1 lecture)
e. Case studies of successful XR applications (2 lectures)
4. Game Mechanics and Interaction Design
a. Fundamental game mechanics and interaction design (2 lectures)
b. Game balance and player engagement (2 lectures)
c. Advanced Unity features (Asset Store, third-party tools) (2 lectures)
d. Game testing and user feedback analysis (2 lectures)
e. Project management in game development (1 lecture)
5. AI in Game Development
a. Basic concepts of AI in gaming (1 lecture)
b. Designing AI-Driven Non-Player Characters (NPCs) with realistic behaviors (1
lecture)
c. Leveraging AI to create dynamic game levels, quests, and world elements (1 lecture)
d. AI-driven interaction in XR (1 lecture)

Structure and Learning Methodologies:
Lectures are conducted in the lab for 2 x 75 minutes per week.
Computer Resources:
The course requires access to computers with Unity Engine installed. We recommend Windows computers with
a reasonably capable graphics card. The project is one of the main assessments of this course. The students
are asked to develop a game and evaluate according to the gameplay mechanics and technical
performance. The group project consists of two main tasks. The first task must be submitted and
evaluated prior to the add-drop period. A final demonstration of the project is scheduled for the last
week of the term. Additionally, the course's final exam is practical and to be completed during the
final week of study.
