COSC 201 Computer Systems Organization
(2 Lecture, 3 Laboratory – 3 Credits)
Prerequisite: COSC 101
Course Catalog Description:
This course thoroughly explains computer logical organization, including components and
interrelationships. It covers the central processor’s native language and basic architectures for
high-performance design. Topics include Von Neumann architecture, low-level aspects of C
programming, data representation, computer arithmetic, assembly language programming,
and digital logic design.
Textbook:
• Computer Systems: A Programmer’s Perspective by Randal E. Bryant and David R.
O’Hallaron. Publisher: Pearson, 3rd Edition, 2015. ISBN: 978-0134092669.
Reference Materials:
• Low-Level Programming: C, Assembly, and Program Execution on Intel® 64
Architecture by Igor Zhirkov. Publisher: Apress, 1st Edition, 2017. ISBN: 978-
1484224021.
Course Topics:
1. Overview: Bit representation of information, program translation, compilation systems. (2
lectures)
2. Overview: Hardware organization, processors, instructions, memory hierarchies. (2
lectures)
3. Assembly programming: Introduction and program structure. (2 lectures)
4. Low-level C programming: Pointers and arrays, functions, dynamic memory management.
(2 lectures)
5. Representation and manipulation of information: information storage, integer
representations, integer arithmetic, Floating point, arithmetic, and logical operations. (4
lectures)
6. Machine-level representation of programs: Assembly addresses and memory allocation. (4
lectures)
7. Processor architecture: Digital logic design. (4 lectures)
8. Processor architecture: Instruction set architecture, sequential and pipelined
implementations. (4 lectures)
9. Memory hierarchy: Storage technologies, locality, cache levels, I/O, and disks. (4 lectures)
10. Optimizing program performance: Eliminating loop inefficiencies, reducing procedure
calls, eliminating unneeded memory references, loop unrolling, and Enhancing parallelism.
(2 lectures)
Course Structure and Methodology:
Lectures are 2 x 50 minutes; Laboratory sessions are 1 x 150 min per week. The course is
delivered in the form of classroom lectures, problem solving sessions, and laboratories work
done individually. Individual assignments and quizzes are held throughout the semester to
reinforce knowledge of the material.

Lab Topics:
1. Assembly programming: Introduction and program structure.
2. Low-level C programming: Pointers and arrays, functions, dynamic memory
management.
3. Representation and manipulation of information: information storage, integer
representations, integer arithmetic
4. Representation and manipulation of information: Floating point arithmetic
5. Machine-level representation of programs: Assembly addresses and memory, flow
control, stack frames.
6. Machine-level representation of programs: Instructions, array allocation and access.
7. Processor architecture: Instruction set architecture.
8. Processor architecture: sequential and pipelined implementations.
9. Memory hierarchy: Storage technologies, locality, cache levels.
10. Memory hierarchy: writing cache-friendly code, I/O and disks.
11. Optimizing program performance: Eliminating loop inefficiencies, reducing procedure
calls, eliminating unneeded memory references, loop unrolling.
12. Optimizing program performance: Enhancing parallelism, understanding memory
performance, identifying, and eliminating performance bottlenecks.
Computing Resources:
A standard computer science lab with personal computers; C compiler and Assembler; systems
diagnosis and performance monitoring tools.
