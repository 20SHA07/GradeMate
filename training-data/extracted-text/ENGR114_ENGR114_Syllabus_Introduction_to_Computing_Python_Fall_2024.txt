COSC 114 Introduction to Computing - Python
(3 Lecture, 3 Laboratory – 4 Credits)
Prerequisite: None
Course Catalog Description:
This course introduces computer systems, including computer hardware components, operating systems,
compiling, debugging, libraries, and linking. It focuses on programming-based problem-solving that
covers the program development lifecycle. It includes imperative programming such as data types,
conditional expressions and statements, repetitive structures, arithmetic and logic operators, functions,
arrays, strings, data structures (database, tuple), and file Input/Output (I/O).
Textbook:
Python Programming: Using Problem-Solving Approach by R. Thareja, Publisher: Oxford University
Press, 2017, ISBN: 978-0-19-948017-3
Reference Materials:
How to Think Like a Computer Scientist: Learning with Python 3. Documentation Release 3rd Edition,
Peter Wentworth, Jeffrey Elkner, Allen B. Downey and Chris Meyers, April 2018 (available online:
https://media.readthedocs.org/pdf/howtothink/latest/howtothink.pdf)
Course Topics:
1. Introduction to computer units and computer language: Machine language, Assembly Language,
and High-level language. (3 lectures)
2. Introduction to Python programming environments. (1 lecture)
3. Syntax and semantics concepts, memory concepts, basic data type declarations and their ranges,
output formatting for data types, assignments, arithmetic and logic operators, operators’
precedence, and associativity. (3 lectures)
4. Problem-solving approaches and algorithms using pseudocode and flowchart. (3 lectures)
5. Control structures I (selections): if, else, elif, selection structures. (3 lectures)
6. Control structures II (repetitions): for, and while loop repetition structures, counter controlled vs.
Sentinel-controlled loop structures, nested loops, break and continue program control statements.
(4 lectures)
7. Functions: passing information to and from functions, scope and visibility of identifiers, iterative
vs. recursive functions. Built-in functions and user-defined functions. (5 lectures)
8. Lists: declaring, passing to functions, linear search, multi-dimensional, sorting. Manipulating of
Lists 1D and 2D. (5 lectures).
9. Strings: Fundamentals of characters and strings, string manipulation functions in Python (ex: find,
len, etc.), string user-defined functions (ex: upper, count, etc.). (4 lectures)
10. Data Structures: dictionary, tuple, passing and returning to/from function. (4 lectures)
11. File I/O: streams insertion and extraction, stream manipulators, open, read, write, and update. (4
lectures)
12. Introduction to Scientific computing using NumPy (3 lectures)
Course Structure and Methodology:
Lectures are 3 x 50 minutes per week; Laboratory session is 1 x 150 min per week
